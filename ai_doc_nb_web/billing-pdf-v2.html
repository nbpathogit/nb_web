Billing & Billing PDF V2 System Reference

Standard billing reports and the Billing PDF V2 system (billing_pdf_2.php)

1. Overview & Comparison (V1 vs V2 vs V3)

The Billing PDF V2 system (billing_pdf_2.php) generates official invoice documents (ใบแจ้งหนี้) for NB Pathology Center. It represents the second generation of invoice generation, sitting between legacy V1 (billing_pdf.php) and modern V3 (billing_pdf_3.php).

2. Architecture & File Structure

Unlike V3 which is completely self-contained in its own directories and suffixed files, V2 is a hybrid system that uses billing_pdf_2.php as its UI, but shares the base PDF templates (pdf_invoice/) and shared generator (billing_pdf_show.php), while introducing exclusive subarray logic in ajax_billing/getBillingGroupBySN_2.php.

3. Key Differences in Data Processing: V2 vs V1 & V3

1. Nested Subarray Rendering in Group 2 (SN List)

In V1, billinngListAll_g2 concatenated descriptions into a single string with slashes (/). In V2 (via ajax_billing/getBillingGroupBySN_2.php), each case contains an array of distinct stain records in subarray:

// V2 getBillingGroupBySN_2.php merges NM (normal) and SP (special) stains:
$aa = ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_nm($conn, ...);
$bb = ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_sp($conn, ...);
$billings[$key]['subarray'] = array_merge($aa, $bb);

In billing_pdf_2.php, the JavaScript rendering function (drawbill_list_all_page_g2) sets rowspan="'+subarray+'" on patient identification columns, outputting a multi-row nested table per surgical number.

2. Explicit Unit Price in Group 3 (Summary by Code)

In V1, the unit price column in drawbill_list_all_page_g3 was commented out. In V2, the ราคาต่อหน่วย (บาท) column is active and included in the table header, data row, and footer span (expanded colspan from 4 to 5).

3. Inline Code2 Editing

V2 provides an interactive modal (#editNumberModal) triggered by double-clicking on any code2 value in the DataTable, submitting updates directly via ajax_ServiceBilling/serviceBillingSetCode2.php.

4. Maintenance & Development Guidelines

Important Rule: Because Billing PDF V2 shares template files in pdf_invoice/ and endpoints in ajax_billing/ with V1, any modifications to base files like billingletter1.php or billing_pdf_show.php will affect both V1 and V2!
  • When modifying V2: Be mindful of shared assets. If changes might break legacy V1, consider whether the work should be done in V3 instead.
  • When adding features: Modern enhancements are primarily developed in V3 (billing_pdf_3.php) because V3 is fully isolated. V2 remains active in the sidebar under #manage_bill_dropdown as a stable production alternative.
