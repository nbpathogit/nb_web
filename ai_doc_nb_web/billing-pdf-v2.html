Billing & Billing PDF V2 System Reference

Standard billing reports and the Billing PDF V2 system (billing_pdf_2.php)

1. Overview & Comparison (V1 vs V2 vs V3)

The Billing PDF V2 system (billing_pdf_2.php) generates official invoice documents (ใบแจ้งหนี้) for NB Pathology Center. It represents the second generation of invoice generation, sitting between legacy V1 (billing_pdf.php) and modern V3 (billing_pdf_3.php).

2. Architecture & File Structure

Unlike V3 which is completely self-contained in its own directories and suffixed files, V2 is a hybrid system that uses billing_pdf_2.php as its UI, but shares the base PDF templates (pdf_invoice/) and shared generator (billing_pdf_show.php), while introducing exclusive subarray logic in ajax_billing/getBillingGroupBySN_2.php.

3. Detailed Workflow: "1) preview bill by date range" (Button 1)

When the user clicks #btn_get_bill_by_range in billing_pdf_2.php (lines 464–995), the system executes a strict sequential workflow consisting of reading filters, reloading the reference DataTable, and running 7 synchronous AJAX calls:

  1. Input Extraction: Reads hospital_id, hospital_name from #phospital_id_bill, and dates from #startdate_billing and #enddate_billing.
  2. Reload Reference DataTable (#billing_table): Queries ajax_billing/getBillbyHospitalbyDateRange.php with DataTables, configuring export buttons (Excel, CSV, PDF) and double-click modal editing on code2 (target 14).
  3. Sequential Synchronous AJAX Execution (async: false):
    • getBillbyHospitalbyDateRangeSumPrice.php → Computes net amount (bcost) and total item count (bcount).
    • getCostGroupbyServiceTyoebyHospitalbyDateRange.php → Summarizes total cost by service type into #bill_hospital_by_service_price.
    • getBillingGroupBySN_2.php → Groups items by SN and merges subarray_nm with subarray_sp into subarray, then executes drawbill_list_all_page_g2(datajson) (line 1249) to construct the Page 4 (Group 2) nested table inside #bill_list_all_g2.
    • getBillingGroupBySNCount.php → Queries count of unique SNs and updates #bill_count_bysn_list.
    • getBillingGroupByCode.php → Aggregates records by official Comptroller General code and executes drawbill_list_all_page_g3(datajson) with active unit price column into #bill_list_all_g3.
    • getBillingGroupByCodeCount.php → Counts unique billing codes and populates #bill_count_bycode_list.
    • getBillingHospitalOneByOne.php → Fetches itemized case breakdown and executes drawbill_list_all_page_g4(datajson) into #bill_list_all_g4.
    • getHospital.php → Retrieves hospital tax ID and address for #bill_hospital_taxid and #bill_hospital_address.
  4. Date & Parameter Population: Converts dates to Thai Buddhist Era (พ.ศ.), populates hospital parameters, sets net price, converts amount to Thai Baht text spelling (#bill_hospital_net_price_spell), and fills manager name (#bill_manager).
  5. Completion Alert: Displays alert("Done Preview step 1.");, allowing the user to click 2) Preview on web page.

4. Key Differences in Data Processing: V2 vs V1 & V3

1. Deep Dive: กลไกการสร้างตารางนับตาม SN (Surgical Number) ใน billing_pdf_2.php [↑ กลับไปตาราง Endpoints]

ในระบบ V1 เดิม ไฟล์ billinngListAll_g2 ใช้วิธีนำข้อความรายการตรวจมาต่อกันด้วยเครื่องหมาย Slash (/) ภายในแถวเดียว แต่ใน V2 (และ V3) ได้ปรับโครงสร้างข้อมูลใหม่ทั้งหมดเป็นแบบ Hierarchical Tree (ลำดับชั้น แม่-ลูก) โดยส่งผ่าน AJAX getBillingGroupBySN_2.php เพื่อนำมาวาดตารางแยกรายการย้อมตรวจหลายแถวย่อยด้วย drawbill_list_all_page_g2(datajson):

ภาพรวมขั้นตอนการทำงาน (Workflow Summary):

  1. Client AJAX Call: ส่งคำขอด้วย url: 'ajax_billing/getBillingGroupBySN_2.php' พร้อมพารามิเตอร์ hospital_id, startdate, enddate
  2. Query เคสหลัก (Parent): เรียก $billings = ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2(...) เพื่อดึงเคสจัดกลุ่มตามเลข SN (p_sn)
  3. Loop ดึงรายการย่อย x2 (Children Subarrays): วนลูปแต่ละเคสด้วย foreach เพื่อเรียก 2 ฟังก์ชันย่อย:
    • $aa = ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_nm(...) → รายการย้อมปกติ (Normal Stains)
    • $bb = ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_sp(...) → รายการย้อมพิเศษ (Special Stains)
  4. Merge & Append: รวม $aa และ $bb เข้าด้วยกันผ่าน array_merge() แล้วแนบเป็น $billings[$key]['subarray']
  5. Client Rendering: เมื่อได้รับ JSON กลับมา ฝั่ง Client จะส่งข้อมูลเข้าฟังก์ชัน drawbill_list_all_page_g2(datajson) เพื่อสร้างตาราง HTML ผสานเซลล์ด้วย rowspan ตามจำนวนรายการใน subarray.length

ตารางสรุปฟังก์ชันและไฟล์ที่ถูกเรียกใช้งาน (Backend Controller & Models):

ลำดับการทำงาน ฟังก์ชันที่เรียก (Called Function) ไฟล์ต้นทาง หน้าที่และผลลัพธ์ที่ได้
1. Parent Cases ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2($conn, $hosp_id, $start, $end) classes/ServiceBilling.php (Line 935) ดึงรายการเคสหลักระดับผู้ป่วย จัดกลุ่มตาม Surgical Number (p.pnum) คืนค่าข้อมูลทั่วไป เช่น p_sn, p_hn, p_admit_date, patient_name, clinicien_name และยอดรวมค่าบริการ
2. Normal Stains (NM) ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_nm($conn, $hosp_id, $start, $end, $sn) classes/ServiceBilling.php (Line 1561) วนลูปเรียกต่อเคส โดยส่ง $billings[$key]['p_sn'] เข้าไปดึงรายการย้อมปกติ (st.service_typea_id = 1) คืนค่า b_description, b_cost_sum_nm, b_cost_sum_all
3. Special Stains (SP) ServiceBilling::getBillbyHospitalbyDateRangeGroupBySN_2_subarray_sp($conn, $hosp_id, $start, $end, $sn) classes/ServiceBilling.php (Line 1652) วนลูปเรียกในเคสเดียวกัน ดึงรายการย้อมพิเศษ/ตรวจพิเศษ (st.service_typea_id = 2) คืนค่า b_description, b_cost_sum_sp, b_cost_sum_all
4. Merge Subarrays $billings[$key]['subarray'] = array_merge($aa, $bb); ajax_billing/getBillingGroupBySN_2.php รวมอาร์เรย์รายการย้อมปกติ $aa และรายการย้อมพิเศษ $bb เข้าเป็นก้อนเดียวกัน แล้วแนบกลับเข้าเคสหลัก จากนั้น echo json_encode($billings);

การแสดงผลฝั่ง Client (Client-Side Rendering):

ในไฟล์ billing_pdf_2.php เมื่อ AJAX สำเร็จ จะเรียกฟังก์ชัน drawbill_list_all_page_g2(datajson) (Line 1249):

  • อ่านความยาวของรายการย่อยผ่าน datajson[i].subarray.length
  • กำหนดค่า rowspan="'+subarray+'" ให้กับคอลัมน์ข้อมูลผู้ป่วย (ลำดับ, เลข SN, วันที่รับ, ชื่อผู้ป่วย, HN, แพทย์ผู้ส่ง) ในแถวแรกของเคสนั้น
  • วนลูปแทรกรายการตรวจย่อยจาก subarray ในคอลัมน์รายการตรวจและจำนวนเงิน ทำให้ได้ตารางสรุปค่าบริการแนวนอน (Landscape A4) ที่สวยงามและแสดงรายการย่อยครบถ้วน

2. Explicit Unit Price in Group 3 (Summary by Code)

In V1, the unit price column in drawbill_list_all_page_g3 was commented out. In V2, the ราคาต่อหน่วย (บาท) column is active and included in the table header, data row, and footer span (expanded colspan from 4 to 5).

3. Inline Code2 Editing

V2 provides an interactive modal (#editNumberModal) triggered by double-clicking on any code2 value in the DataTable, submitting updates directly via ajax_ServiceBilling/serviceBillingSetCode2.php.

5. Maintenance & Development Guidelines

Important Rule: Because Billing PDF V2 shares template files in pdf_invoice/ and endpoints in ajax_billing/ with V1, any modifications to base files like billingletter1.php or billing_pdf_show.php will affect both V1 and V2!
  • When modifying V2: Be mindful of shared assets. If changes might break legacy V1, consider whether the work should be done in V3 instead.
  • When adding features: Modern enhancements are primarily developed in V3 (billing_pdf_3.php) because V3 is fully isolated. V2 remains active in the sidebar under #manage_bill_dropdown as a stable production alternative.
