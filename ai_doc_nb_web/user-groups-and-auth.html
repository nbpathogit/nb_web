Per-User Capability Flags vs Group IDs

  • user.role_a: Super-pathologist ownership flag. Checked in $isCurrentPathoIsOwnerThisCase ($u_cur_group_id->id == 2000 && ($_SESSION['user']->id == $job5s[0]['user_id'] || $_SESSION['user']->role_a == 1)).
  • user.role_7: Cytologist capability flag (User::getAllbyCytologist() selects role_7 = 1). Cytologist case ownership ($isCurrentCytologistIsOwnerThisCase) checks $_SESSION['user']->id == $job7s[0]['user_id'].

2. Step-by-Step login.php Execution Flow

  1. Initialization & Subfolder Detection (Lines 1–15): Loads includes/init.php (registers autoloader for classes/*.php and calls session_start()) and extracts $subfolder (e.g., dev3) from $_SERVER['PHP_SELF'].
  2. Already-Logged-In Check (Lines 16–18): Calls Auth::isLoggedIn(). If already authenticated, redirects immediately to /patient.php.
  3. POST Authentication (Lines 20–28):
    • Checks User::isUserNameActive($conn, $_POST['username']) (user_status == 1).
    • Checks User::authenticate($conn, $_POST['username'], $_POST['password']) via password_verify().
    • Calls Auth::login($conn, $_POST['username'], $_POST['subfolder']).
  4. Post-Login Redirects (Lines 29–36):
    • If password is still "changeme" → redirects to /user_change_password.php.
    • Else if $_POST['page_name'] is non-empty → redirects to /{page_name}?id={page_id}.
    • Otherwise → redirects to /patient.php.
