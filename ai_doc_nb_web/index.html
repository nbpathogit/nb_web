B. How login.php Works

  1. Init & Subfolder: Loads includes/init.php (starts session + class autoloader) and detects $subfolder (e.g., dev3) from $_SERVER['PHP_SELF'].
  2. Already Logged In: If Auth::isLoggedIn() is true, redirects immediately to /patient.php.
  3. Active & Password Check (POST): Calls User::isUserNameActive($conn, $username) (user_status == 1) and User::authenticate($conn, $username, $password) (password_verify()).
  4. Session Creation: Calls Auth::login($conn, $username, $subfolder), which stores User, Ugroup, skey, and a 20-minute timeout (1200s) in $_SESSION, and logs the login via Log::add().
  5. Redirects: If password is "changeme" → /user_change_password.php; else if page_name is set → /{page_name}?id={page_id}; otherwise → /patient.php.

3. PHP 7.3 + PHP 8.2+ & MySQL 8.4 Compatibility Rules

Open Full Page →
Rule 1 — Dynamic Properties (PHP 7.3 & PHP 8.2+): Declare all database columns explicitly on classes hydrated via PDO::FETCH_CLASS (User, Ugroup) and place #[\AllowDynamicProperties] on its own line right above class ClassName. PHP 8.2+ reads it as an Attribute; PHP 7.3 ignores it as a # comment.
Rule 2 — ONLY_FULL_GROUP_BY (MySQL 8.4 Error 1055): Always fix the SQL query directly in the PHP model class rather than disabling sql_mode in Database.php. Use standard SQL MAX(...) on non-aggregated joined columns when grouping by a parent key (e.g. GROUP BY p.id). Never use ANY_VALUE() because MariaDB (PHP 7.3) does not support it. 
// Example in Patient::getAllJob1/2/3FinishPhp (classes/Patient.php):
MAX(j.id) as j_id , 
MAX(j.patient_id) as j_patient_id, 
MAX(j.user_id) as j_user_id, 
MAX(j.job_role_id) as j_job_role_id, 
MAX(j.jobname) as j_jobname,
MAX(j.qty) as j_qty,
p.job1qty as p_job1qty,
GROUP_CONCAT(CONCAT(j.pre_name, j.name, ' ',j.lastname) SEPARATOR ',') AS j_owners,
MAX(DATE(j.finish_date)) as j_finish_date

5. Patient Workflows (patient.php, patient_add.php, patient_edit.php)

Open Full Page →

A. Patient Add (patient_add.php & ReportType Groups 1–3)

  • SN Generation: Auto mode (is_autogen == "yes") queries Patient::get_max_sn_run_by_year($conn, $curyear, $sn_type) and zero-pads to 5 digits; Manual mode (is_autogen == "no") combines prenum + yearnum + runnum.
  • Sub-Patient Cloning (super_id): Defaults to Patient::getInit(), or copies parent case fields via Patient::getAll($conn, $_POST['super_id']) when creating a sub-case.
  • Post-Create Presultupdate & Questionnaire Initialization:
  • Group 1 (ReportType::getAllbyGroup1): Pre-created mandatory descriptive sections in patient_add.php (result_type_id 1–4: Specimen, Clinical Diagnosis [skipped on PDF], Gross Description, Microscopic Description) from hardcoded DB table report_type (release_type = 'ยังไม่ออกผล') for non-PN/LN cases. Cannot be deleted in UI; printed below Group 2 on PDF.
  • Group 2 (ReportType::getAllbyGroup2): Diagnostic & Revision sections (result_type_id 11–14: Provisional Diagnosis [ออกผลเบื้องต้น], Pathological Diagnosis, Addendum, Revised) added on-demand via Modal in patient_edit.php (NOT called in patient_add.php). Deletable before release; holds Second Pathologist confirmation; printed at top of PDF (22pt).
  • Group 3 (ReportType::getAllbyGroup3): Pre-created mandatory cervical cytology sections in patient_add.php (result_type_id 21–25: SPECIMEN TYPE, SOURCE, SPECIMEN ADEQUACY, INTERPRETATION, EDUCATIONAL NOTES AND SUGGESTION) from hardcoded DB table (release_type = 'ออกผลแล้ว') for PN and LN cases. Foreach loop assigns name as the main section header for the case's patient_id. (Deep Dive: ReportType Groups 1, 2, 3 Guide →)
  • Auto-Gender JS: Selecting a title in #ppre_name_add (from includes/prenameOption.php) auto-selects #pgender_add (Male, Female, NA).

8. Database Schema Summary (35 Tables in nbpa_data_dev3)

Open Full Page →

The database contains 35 InnoDB tables with 6 declared foreign keys (ON DELETE CASCADE ON UPDATE CASCADE):

  • job.patient_id → patient.id
  • job.job_role_id → job_role.id
  • job.req_id → req_id_sp_slide.id
  • req_id_sp_slide.patient_id → patient.id
  • req_id_sp_slide.job_id → job.id
  • service_billing.patient_id → patient.id

See database-schema.html for the 35-table catalog and database_schema_full.html for full column-level DDL details.
