Group 3 (Cervical Cytology) UResult Initialization

การทำงานของ patient_add.php ในการอ่านตารางฮาร์ดโค้ด report_type (group_type = 3) แล้ววนลูปสร้างเรคคอร์ด uresult (ในตาราง presultupdate) สำหรับเคส PN และ LN

1. ภาพรวมการทำงาน (Workflow Overview)

เมื่อมีการเพิ่มเคสผู้ป่วยใหม่ในระบบผ่าน patient_add.php และเลือกหรือระบุประเภท Surgical Number (sn_type) เป็นประเภทเซลล์วิทยาปากมดลูก (PN หรือ LN) ระบบจะทำการตั้งต้นโครงสร้างผลตรวจทางพยาธิวิทยา (Report Sections) โดยอัตโนมัติ

Step 1: Check Prefix

เงื่อนไข SN Prefix

ตรวจสอบ $sn_type == 'PN' || $sn_type == 'LN' หลังบันทึกเคสคนไข้สำเร็จ

Step 2: Read DB

คิวรี Group 3

อ่านข้อมูลฮาร์ดโค้ดจาก report_type ด้วย group_type = 3 (5 รายการ)

Step 3: Foreach Loop

วนลูปสร้าง Record

นำค่า name ไปเป็นหัวข้อหลัก และผูกกับ patient_id ล่าสุด

Step 4: Ready for Edit

พร้อมให้ลงผลตรวจ

บันทึกเข้าตาราง presultupdate (DOM uresult) เพื่อแสดงใน patient_edit.php

ความหมายของประเภทเคส PN และ LN: • PN = ตรวจเซลล์มะเร็งปากมดลูกแบบเก่า (Conventional cervical cytology)
• LN = ตรวจเซลล์มะเร็งปากมดลูกแบบใหม่ (Liquid-based cervical cytology)

2. ตารางข้อมูลฮาร์ดโค้ดในฐานข้อมูล (Hardcoded Database Table)

คอนดิชั่นของ Group 3 ถูกกำหนดและฮาร์ดโค้ดไว้ในตาราง report_type บนฐานข้อมูล โดยมีฟิลด์ group_type = 3 ซึ่งอ่านผ่าน SQL ต่อไปนี้:

SELECT *
FROM `report_type`
WHERE group_type = 3 
ORDER BY id;

ตารางข้อมูล Group 3 (5 เรคคอร์ดมาตรฐาน):

id group_type name (ชื่อหัวข้อหลัก) release_type options
21 3 SPECIMEN TYPE ออกผลแล้ว (NULL/ว่าง)
22 3 SOURCE ออกผลแล้ว (NULL/ว่าง)
23 3 SPECIMEN ADEQUACY ออกผลแล้ว (NULL/ว่าง)
24 3 INTERPRETATION ออกผลแล้ว (NULL/ว่าง)
25 3 EDUCATIONAL NOTES AND SUGGESTION ออกผลแล้ว (NULL/ว่าง)

3. การวนลูปสร้าง Record ใน patient_add.php

เมื่อ $patient->create($conn) สำเร็จ โค้ดใน patient_add.php (บรรทัด 213–225) จะดึงข้อมูลผ่านคลาส ReportType::getAllbyGroup3($conn) แล้วทำการวนลูปสร้างเรคคอร์ด Presultupdate (หรือที่ในฝั่ง UI/DOM เรียกว่า uresult):

//==Create Presultupdate (uresult) สำหรับเคส PN และ LN =====================
if ($sn_type == 'PN' || $sn_type == 'LN') {
    $cur_patient_id = $patient->id;
    $typelists = ReportType::getAllbyGroup3($conn);

    foreach ($typelists as $typelist) {
        $resultreport = Presultupdate::getInitObj();
        $resultreport->group_type = $typelist['group_type'];     // 3
        $resultreport->patient_id = $cur_patient_id;             // ผูกกับคนไข้เคสนี้
        $resultreport->result_type = $typelist['name'];          // นำ name ไปเป็นชื่อหัวข้อหลัก
        $resultreport->result_type_id = $typelist['id'];         // ID อ้างอิงตาราง report_type (21-25)
        $resultreport->release_type = $typelist['release_type']; // 'ออกผลแล้ว'
        $resultreport->create($conn);
    }
}
//==End of Create Presultupdate =========================================

การจับคู่ข้อมูล (Field Mapping):

แหล่งข้อมูล: report_type

• id (21 to 25)
• group_type (3)
• name (เช่น SPECIMEN TYPE)
• release_type ('ออกผลแล้ว')
→

ตารางปลายทาง: presultupdate (uresult)

• result_type_id = id
• group_type = group_type
• result_type = name (ชื่อหัวข้อ)
• release_type = release_type
• patient_id = $patient->id

4. พฤติกรรมในขั้นตอนถัดไป (Downstream Behaviors)

ขั้นตอน / หน้าจอ ไฟล์ที่เกี่ยวข้อง พฤติกรรมและการทำงาน
DOM Binding includes/data2DOM.php ส่งออกลิสต์ของ Group 3 สู่ DOM ภายใต้คลาส .uresultinxlist3 และ .uresultReleaseSetlistGroup3 เพื่อให้ JavaScript จัดการสถานะการออกผล
การแสดงผลหน้า Edit includes/patient_form_080_job7_result.php เรนเดอร์ฟอร์มใส่ผลตรวจสำหรับนักเซลล์วิทยา (Cytologist / Job Role 7) และพยาธิแพทย์ (Pathologist / Job Role 5) โดยแสดงเรียงตามลำดับ ID (21→25)
สิทธิ์การลบ (Delete Gate) patient_edit.php ไม่สามารถลบได้: ปุ่มลบ (Delete) ในระบบจะอนุญาตให้ลบเฉพาะ group_type == 2 เท่านั้น สำหรับ group_type == 3 ถือเป็น Mandatory Section ห้ามลบ
การดับเบิ้ลคอนเฟิร์ม (Role 6) patient_edit.php (Status 13000) บล็อกแพทย์ผู้คอนเฟิร์มผล (Second Pathologist) จะถูกผูกเข้ากับเรคคอร์ดสุดท้ายของ Group 3 คือ id = 25 (EDUCATIONAL NOTES AND SUGGESTION)
การพิมพ์รายงาน PDF patient_pdf.php / patient_format_result_pdf_3.php จัดพิมพ์ผลตรวจเรียงลำดับแบบ ASC (ตาม id 21 ถึง 25) โดยใช้เทมเพลตฟอนต์ขนาด 22pt

5. เปรียบเทียบ Report Groups ทั้ง 3 กลุ่ม

Group คลาส & ฟังก์ชัน Surgical Number ที่ใช้ การลบ (Delete) การพิมพ์ PDF
