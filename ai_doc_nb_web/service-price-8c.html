Hospital Service Pricing (8 Columns) — nb_price_8c.php

ระบบตั้งและจัดการราคาค่าบริการสิ่งส่งตรวจและค่าย้อมพิเศษ เพื่อนำไปคำนวณบิลและออกใบแจ้งหนี้ภายหลัง

1. วัตถุประสงค์และภาพรวมของระบบ (Purpose & System Overview)

🎯 จุดประสงค์หลักของหน้านี้ (Core Purpose):
nb_price_8c.php ("ดูและจัดการรายการค่าบริการ8คอลั่ม") ถูกแยกเป็นกลุ่มฟังก์ชันเฉพาะทางต่างหาก ไม่จัดรวมอยู่ในงานฉลากสติกเกอร์หรือมาสเตอร์ดาต้าทั่วไป โดยมีหน้าที่โดยตรงคือ:
  • กำหนดอัตราค่าบริการ (Service Pricing): บันทึกราคาค่าตรวจชิ้นเนื้อและค่าย้อมพิเศษลงในตาราง service_price_list สำหรับแต่ละโรงพยาบาลลูกค้า รวมถึงราคามาตรฐานส่วนกลาง (hospital_id = 0)
  • นำไปคิดบิลภายหลัง (Subsequent Billing Calculation): เป็นฐานข้อมูลราคาต้นทาง เมื่อเจ้าหน้าที่บันทึกการส่งตรวจชิ้นเนื้อ (Slide 1) หรือส่งย้อมพิเศษ (Slide 2) ระบบจะดึงราคาจากตารางนี้ไปคำนวณยอดเงินในตาราง service_billing เพื่อนำไปออกใบแจ้งหนี้ (Billing Invoice PDF V3) ต่อไป

เมนูการเข้าถึง: แถบเมนูด้านบน → จัดการตาราง และ ตั้งค่า (#manage_table) → ดูและจัดการรายการค่าบริการ8คอลั่ม (#price_tab_8c)

การควบคุมสิทธิ์: ต้องผ่านการล็อกอิน (Auth::requireLogin()) บล็อกผู้ใช้กลุ่มลูกค้า (กลุ่ม 5000 แพทย์ลูกค้า และ 5100 โรงพยาบาลลูกค้า) อนุญาตเฉพาะเจ้าหน้าที่ห้องแลปและผู้ดูแลระบบเท่านั้น พร้อมทั้งบันทึกการเข้าใช้งานลงตาราง log

2. รูปแบบการ Paste ข้อมูลจาก Excel (8 คอลัมน์แบบ Tab-Separated)

ผู้ใช้งานสามารถ Copy ข้อมูลจากตาราง Microsoft Excel หรือ Google Sheets แล้ววางลงในกล่องข้อความ #nb_price_add_txt_area_8c ได้ทันที โดยระบบกำหนดรูปแบบ 8 คอลัมน์ดังนี้:

ลำดับ → code → รายการ → หน่วยนับ → ราคา → comment → service_id → service_description

คอลัมน์ (Index) ชื่อหัวตาราง ฟิลด์ใน DB ชนิดข้อมูล คำอธิบายและตัวอย่าง
line[0] ลำดับ number int(11) ลำดับที่ในใบราคา เช่น 1, 2, 3
line[1] code speciment_num int(10) รหัสหัตถการหรือสิ่งส่งตรวจ เช่น 33000, 38001
line[2] รายการ specimen text ชื่อและรายละเอียดการตรวจ เช่น Biopsy or small specimen
line[3] หน่วยนับ unit_count varchar(30) หน่วยนับ เช่น ชิ้น, ตัวอย่าง, สไลด์
line[4] ราคา price int(11) ราคาเป็นบาท ระบบจะตัดเครื่องหมายจุลภาค , ออกให้อัตโนมัติ (เช่น 1,200 → 1200)
line[5] comment comment text หมายเหตุ เช่น ราคามาตรฐาน, เหมาจ่าย
line[6] service_id jobtype tinyint(4) รหัสชนิดบริการ ผูกกับ service_type.id (1–8)
line[7] service_description service_des varchar(256) คำอธิบายชนิดบริการ เช่น ตรวจชิ้นเนื้อศัลยพยาธิวิทยา, ตรวจพิเศษ
ตัวอย่างข้อมูล TSV ดิบที่วางจาก Excel: 
1	33000	Biopsy or small specimen	ชิ้น	400	ราคามาตรฐาน	1	ตรวจชิ้นเนื้อศัลยพยาธิวิทยา
2	33001	Appendix	ชิ้น	500	ราคามาตรฐาน	1	ตรวจชิ้นเนื้อศัลยพยาธิวิทยา
3	34000	Special Stain (AFB)	สไลด์	200	ราคามาตรฐาน	2	ตรวจพิเศษ

ไฟล์ตัวอย่างอ้างอิง (Reference Sheet): ด้านล่างของหน้าจอมีลิงก์ดาวน์โหลดไฟล์ตัวอย่างค่าบริการ: file/ตัวอย่างค่าตรวจ Update 3 มี.ค. 67 .xlsx

3. สถาปัตยกรรมและ AJAX Endpoints (ajax_nb_price_8c/)

1. ดึงข้อมูลแสดงผล (Query & Render)

ไฟล์: ajax_nb_price_8c/get_specimen_8c.php
รับพารามิเตอร์ hospital_id และ type_id เรียก ServicePriceList::getSpecimenByHospitalID() หากเลือก type_id = 0 จะแสดงผลทุกชนิดบริการของโรงพยาบาลนั้น และวาดตารางลงใน #nb_price_tbl_8c

2. ลบข้อมูลยกชุด (Bulk Delete)

ไฟล์: ajax_nb_price_8c/delSpecimen_8c.php
เมื่อกดปุ่ม #nb_price_del_btn_8c ระบบจะยืนยันกับผู้ใช้แล้วเรียก ServicePriceList::delSpecimenByHospitalID() สั่ง DELETE FROM service_price_list WHERE hospital_id = :h_id [AND jobtype = :type_id]

3. บันทึกข้อมูลแบบชุดใหญ่ (Batch Multi-Insert)

ไฟล์: ajax_nb_price_8c/addMultRecordiSpecimen_8c.php
nb_price_8c.js จะแยกบรรทัดและคอลัมน์ จัดทำเป็น JSON Array ส่งผ่าน AJAX POST จากนั้นสคริปต์ PHP จะตัดจุลภาคออกจากราคา, ป้องกัน SQL Injection ด้วย addslashes(), ผูกรหัส hospital_id และ add_user_id แล้วประกอบเป็นคำสั่ง Multi-Row INSERT INTO service_price_list VALUES (...), (...) รันผ่าน ServicePriceList::createBySQL() ในคิวรีเดียว

4. ระบบ Download & Upload Excel + ประวัติไฟล์ (upload_excel_8c.php, get_excel_history_8c.php, download_excel_8c.php)

• Download Excel (#nb_price_excel_btn_8c): ส่งออกข้อมูลในตาราง #nb_price_tbl_8c เป็นไฟล์ .xlsx 8 คอลัมน์ (ลำดับ(number), โค้ด(code), รายการ(detail), ต่อหน่วย(unit), ราคา(price), คอมเม้นท์(comment), ไอดีชนิด(type), ชนิดของรายการ(type Description)) โดยซ่อนคอลัมน์ดีบัก row_id, hospital, create date ด้วย style="display:none;"
• Upload Excel (#nb_price_upload_btn_8c): อ่านไฟล์ .xlsx/.xls ด้วย SheetJS และตรวจสอบความถูกต้องทั้งฝั่ง Client และ Server (ลำดับ/โค้ด/ราคา ต้องเป็นตัวเลขและห้ามว่าง, รายการห้ามว่าง, ไอดีชนิดต้องเป็นตัวเลขที่มีอยู่ในตาราง service_type.id เท่านั้น พร้อมแสดงตารางอ้างอิง service_type บนหน้าเว็บ)
• เก็บไฟล์และประวัติ (classes/ServicePriceExcelFile.php): บันทึกไฟล์จริงไว้ใน nb_price_8c_uploads/ (มี .gitkeep) และบันทึกประวัติลงตาราง service_price_excel_file พร้อมระบบ JSON Fallback (history_index.json) กรณีที่ DB User บนเซิร์ฟเวอร์จริงไม่มีสิทธิ์ CREATE TABLE

4. การเชื่อมโยงไปยังระบบคิดบิลและออกใบแจ้งหนี้ (Billing Pipeline)

ข้อมูลราคาที่จัดการผ่าน nb_price_8c.php เป็นหัวใจสำคัญของวงจรคิดเงินในระบบ NB Patho:

ขั้นตอนการทำงาน ไฟล์ที่เรียกใช้ ฟังก์ชันของ ServicePriceList การส่งต่อไปยังระบบบิล
1. เลือกสิ่งส่งตรวจ (Slide 1) ajax_slide1_specimen/getSpecimenList1.php getSpecimenByHospitalIDJoptypeSpecimen() ดึงรายการราคาที่มี jobtype IN (1, 4, 5, 8) ตามโรงพยาบาลของเคสคนไข้
2. เลือกย้อมพิเศษ (Slide 2) ajax_slide2__special/getSpecimenList2.php getSpecimenByHospitalIDJoptypeSpecialStainging() ดึงรายการย้อมพิเศษที่มี jobtype IN (2, 3, 6, 7) ตามโรงพยาบาลและชนิดบริการ
3. บันทึกลงตารางบิล ระบบลงทะเบียนเคสและบันทึกผล บันทึกลงตาราง service_billing คัดลอก specimen_id, code_description, description, และ cost ไปเก็บไว้ในตาราง service_billing
4. คำนวณและพิมพ์ใบแจ้งหนี้ billing.php และ billing_pdf_3.php ระบบ Billing PDF V3 รวบรวมรายการจาก service_billing มาคำนวณยอดเงินรวม สรุปกลุ่มบริการ และพิมพ์ใบแจ้งหนี้ทางการแบบ A4 (Page 1–6)

5. ตารางเปรียบเทียบในตระกูลหน้าจัดการราคา (nb_price*.php)

ไฟล์หน้าจอ จำนวนคอลัมน์ สถานะการใช้งาน ความสามารถหลักและข้อแตกต่าง
nb_price.php 6 ปิดใช้งาน (Comment ไว้) ระบบเดิม ต้องเลือกชนิดบริการจาก Dropdown ก่อน วางได้ทีละชนิด
nb_price_8c.php 8 เปิดใช้งาน (หน้าหลัก Standard) วางได้หลายชนิดบริการพร้อมกันในรอบเดียว โดยมี service_id กำกับในแต่ละแถว
nb_price_9c.php 9 เปิดใช้งาน (ขั้นสูง Advanced) เพิ่มคอลัมน์ code2 สำหรับรหัสตรวจเบิกจ่ายคู่ขนานของโรงพยาบาล
