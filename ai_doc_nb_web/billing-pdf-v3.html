Billing & Billing PDF V3 System Reference

Standard billing reports (billing.php) and the self-contained Billing PDF V3 system (billing_pdf_3.php)

1. Standard Billing Report (billing.php & js/billing_a.js)

  • Purpose: Date-range billing reports and service cost tables per patient, clinician, hospital, or pathologist.
  • Touchpoints: billing.php, billing_by_billingdate.php, js/billing_a.js, and classes/ServiceBilling.php.

2. Billing PDF V3 System (billing_pdf_3.php)

The Billing PDF V3 system generates invoice documents (ใบแจ้งหนี้) for NB Pathology Center. All V3 files use the _3 suffix and are completely independent of V1 (billing_pdf.php) and V2 (billing_pdf_2.php).
