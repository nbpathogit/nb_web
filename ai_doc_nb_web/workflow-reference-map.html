Surgical Numbers, Service Types & Invoice Mapping

Reference for sn_prefix (patient.sn_type), service_type, and invoice_list

1. Surgical Number Prefixes (sn_prefix / patient.sn_type)

Patient numbers are formatted as prefix + 2-digit year + 5-digit run (e.g., SN2600001) using Patient::get_max_sn_run_by_year() and Util::prepend_string_with_zero(5, $runnum).
