Sticker Label Printing & Master Data Reference

generate_label.php (V1 & V2) and Master Data CRUD screens

1. Sticker Label Printing (generate_label.php & generate_labelv2.php)

  • Queue Table: labelprint_tmp_a via LabelPrint::getAllbyUserID() (scoped per user via $_SESSION['userid']).
  • V1 (generate_label.php): Single-patient SN selection by accept date → assigns letter, start_num, and end_num → posts to ajax_data/generate_label_add_record.php.
  • V2 (generate_labelv2.php): Multi-row batch selection with checkboxes for letters A–E → posts JSON batch to ajax_data/generate_label_add_multiple_record.php. Marks existing queued SNs as Finish to prevent duplicates.
  • Shared AJAX Endpoints: ajax_data/generate_label_get_record.php and ajax_data/generate_label_get_SN_by_date.php.
  • PDF Export Templates: sn_pdf1.php, sn_pdf2.php, sn_sp_pdf1.php, and sn_sp_pdf2.php (A4 sticker sheet, 76mm × 20mm sticker sheet, specimen labels with/without grid).
