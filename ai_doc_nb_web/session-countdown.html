ระบบการนับเวลาถอยหลัง (Session Countdown & Auto-Logout)

สถาปัตยกรรมและกลไกการทำงานของ Time Remain ใน NB Patho (nb_web / dev3)

ภาพรวมโครงสร้างระบบ (Architecture Overview)

ระบบนับเวลาถอยหลังของ NB Patho ออกแบบมาเพื่อรักษาความปลอดภัยของข้อมูลผู้ป่วย โดยจำกัดเวลา Session ไว้ที่ 20 นาที (1,200 วินาที) และแสดงผลนาฬิกานับถอยหลังสีแดงแบบเรียลไทม์บนแถบ Sidebar ด้านซ้ายใต้ข้อมูลผู้ใช้ พร้อมทั้งมีระบบ Auto-Logout อัตโนมัติเมื่อเวลาหมด

Step 1 • Server

Auth.php

กำหนด $sesstion_timelimit_int_sec = 1200 และสร้าง Target Timeout ลงใน $_SESSION

Step 2 • DOM

header.php

ฝังตัวเลข 1200 ลงใน <li class="sesstion_timelimit_int_sec"> และเตรียม #sessioncountdown

Step 3 • Client JS

script.js

เริ่มลูป decrement() ทุก 1 วินาที และแปลงเวลาเป็น H:MM:SS แสดงบนหน้าจอ

Step 4 • Auto Sync

getSrvTimeRemain.php

เรียก AJAX ซิงค์เวลากับเซิร์ฟเวอร์เป็นระยะ (15, 10, 5, 1 นาที และ 2 วิ) เพื่อป้องกันนาฬิกาเบราว์เซอร์เพี้ยน

Step 5 • Modal Popup

Re-Login Popup

เมื่อหมดเวลา (<= -1) เปิด Modal #sessionReloginModal ให้ใส่รหัสผ่านล็อกอินต่อได้ทันทีโดยหน้าไม่รีเฟรช

Step 6 • Fallback

logout.php

หากไม่มี Modal ใน DOM หรือผู้ใช้เลือกกดปุ่ม "ออกจากระบบ" จะส่งไปยัง logout.php

1. กลไกฝั่งเซิร์ฟเวอร์ (Server-Side: classes/Auth.php)

ควบคุมการคำนวณและตรวจสอบสิทธิ์ในไฟล์ classes/Auth.php:

A. ค่าคงที่เวลา Timeout (Line 12)

// classes/Auth.php
public static $sesstion_timelimit_int_sec = 1200; // 1200 seconds = 20 minutes

B. เมื่อผู้ใช้ล็อกอิน (Auth::login, Lines 86–91)

date_default_timezone_set('Asia/Bangkok');
$_SESSION['setSrvTimeLimitIntSecs'] = Auth::$sesstion_timelimit_int_sec; // 1200
$curTime = Time();
$_SESSION['curSrvTimeIntSecs'] = $curTime;
$_SESSION['targetSrvTimeOutIntSecs'] = $curTime + $_SESSION['setSrvTimeLimitIntSecs']; // เวลาปัจจุบัน + 20 นาที
$_SESSION['targetSrvTimeRemainIntSecs'] = $_SESSION['targetSrvTimeOutIntSecs'];

C. การต่ออายุเวลาเมื่อเปิดหน้าใหม่ (Auth::requireLogin, Lines 47–57)

ในทุกหน้าเว็บที่มีการตรวจสิทธิ์ หากผู้ใช้ยังคงใช้งานหน้าเว็บอยู่ ระบบจะรีเฟรชต่ออายุ Session ให้อีก 20 นาทีอัตโนมัติ:

$curTime = Time();
$_SESSION['setSrvTimeLimitIntSecs'] = Auth::$sesstion_timelimit_int_sec;

if ($curTime >= $_SESSION['targetSrvTimeOutIntSecs']) {
    Auth::logout();
    Url::redirect('/login.php');
} else {
    $_SESSION['curSrvTimeIntSecs'] = $curTime;
    // ขยายเวลาหมดอายุออกไปอีก 20 นาที
    $_SESSION['targetSrvTimeOutIntSecs'] = $curTime + $_SESSION['setSrvTimeLimitIntSecs'];
}

D. ฟังก์ชันคำนวณเวลาที่เหลือจริง (Auth::getSrvTimeRemain, Lines 148–154)

public static function getSrvTimeRemain() {
    date_default_timezone_set('Asia/Bangkok');
    $curTime = Time();
    $_SESSION['targetSrvTimeRemainIntSecs'] = $_SESSION['targetSrvTimeOutIntSecs'] - $curTime;
    return $_SESSION['targetSrvTimeRemainIntSecs'];
}

2. การแสดงผลและการส่งต่อข้อมูลสู่ DOM (includes/header.php & header_c.php)

ในไฟล์ Header จะมีองค์ประกอบ HTML 2 จุดสำคัญ:

A. จุดแสดงผลเวลานับถอยหลังและปุ่มล็อกเอ้าต์ (Visible Element in Sidebar, Lines 120–127)

อยู่ใต้แถบแสดงชื่อและกลุ่มของผู้ใช้งานในแถบ Sidebar ด้านซ้าย พร้อมปุ่มกด ออกจากระบบ (Log Out) ใต้ตัวเลขเวลา:

<div class="d-flex flex-column ms-4 mb-4">
    <div class="position-relative">
        <b><span style="font-size: 1em;">Time Remain <span id="sessioncountdown" style="color:red;"></span></span></b>
    </div>
    <div class="mt-1">
        <a href="logout.php" class="text-danger small fw-bold text-decoration-none" title="ออกจากระบบ"><i class="fa-solid fa-right-from-bracket me-1"></i><b>ออกจากระบบ (Log Out)</b></a>
    </div>
</div>

B. จุดส่งค่าตัวแปรจาก PHP สู่ JavaScript (Hidden Element, Line 382)

นำค่า Auth::$sesstion_timelimit_int_sec (1200) มาฝังไว้ใน attribute tabindex แบบซ่อน:

<?php $hidden_data2dom = true; ?>
<li class="sesstion_timelimit_int_sec" tabindex="<?= Auth::$sesstion_timelimit_int_sec ?>" style="<?= $hidden_data2dom ? "display: none;" : "" ?>">
    Auth::$sesstion_timelimit_int_sec :: <?= Auth::$sesstion_timelimit_int_sec ?>
</li>

3. กลไกการนับเวลาถอยหลังในเบราว์เซอร์ (Client-Side JS: js/script.js)

JavaScript จัดการนับถอยหลังและประสานงานกับเซิร์ฟเวอร์ใน js/script.js:

A. การเริ่มต้นระบบ (Initialization on DOM Ready, Lines 125–152)

// อ่านค่าเวลาตั้งต้น 1200 จาก DOM
var sesstion_timelimit_int_sec = $(".sesstion_timelimit_int_sec").attr('tabindex');
setTimeOutLimitIntSecs = parseInt(sesstion_timelimit_int_sec);
runningWebDownTimeIntSecs = 0;

const date = new Date();
curWebTimeIntSecs = Math.floor(date.getTime() / 1000);
targetWebTimeOutIntSecs = Math.floor(curWebTimeIntSecs + setTimeOutLimitIntSecs);
runningWebDownTimeIntSecs = Math.floor(targetWebTimeOutIntSecs - curWebTimeIntSecs);

showTimeRuning(runningWebDownTimeIntSecs);

// เริ่มต้นนับถอยหลังทุก 1 วินาที
setTimeout(decrement, 1000);

B. ลูปนับถอยหลังและการซิงค์เวลาเซิร์ฟเวอร์ (decrement(), Lines 165–226)

ทุกๆ 1 วินาที ฟังก์ชัน decrement() จะทำงาน:

  • ป้องกันนาฬิกาเบราว์เซอร์เดินเพี้ยน (Server Sync): มีการส่ง AJAX ไปเช็กเวลาจริงกับ Server เมื่อเวลาแสดงผลตรงกับเงื่อนไข:
    • เหลือ 15 นาที (0:15:00)
    • เหลือ 10 นาที (0:10:00)
    • เหลือ 5 นาที (0:05:00)
    • เหลือ 1 นาที (0:01:00)
    • ช่วง 2 วินาทีสุดท้าย (0:00:02 หรือน้อยกว่า)
  • นำค่า servtimeRemainIntSecs จาก Server มาคำนวณ targetWebTimeOutIntSecs ใหม่ให้แม่นยำ
  • อัปเดตเวลาลงหน้าจอผ่าน showTimeRuning(runningWebDownTimeIntSecs)
  • Background Tab Pre-check: หากแท็บถูก Sleep/Background จนเวลาข้าม จะส่ง AJAX ตรวจสอบกับ Server อีกครั้งก่อนสรุปว่าหมดเวลาจริง
  • Session Timeout Modal Trigger: หากเวลาหมดลงจริง (runningWebDownTimeIntSecs <= -1) ระบบจะไม่เด้งออกจากหน้าจอทันที แต่จะคงตัวเลข 0:00:00 และเปิด Popup showSessionReloginModal(): 
    if (runningWebDownTimeIntSecs > -1) {
    // Show time in web page
    showTimeRuning(runningWebDownTimeIntSecs);
    setTimeout(decrement, 1000);
} else {
    // แสดงเวลาเป็น 0:00:00 และเปิด Popup ให้ใส่รหัสผ่านเพื่อทำงานต่อโดยหน้าเว็บไม่หาย
    showTimeRuning(0);
    showSessionReloginModal();
}

C. ฟังก์ชันแปลงวินาทีเป็นรูปแบบเวลา (convertTimeSec2HHMMSS, Lines 265–281)

function convertTimeSec2HHMMSS(runningWebDownTimeIntSecs) {
    var displayedSecs = runningWebDownTimeIntSecs % 60;
    var displayedMin = Math.floor(runningWebDownTimeIntSecs / 60) % 60;
    var displayedHrs = Math.floor(runningWebDownTimeIntSecs / 60 / 60);

    displayedSecsInt = parseInt(displayedSecs);
    displayedMinInt = parseInt(displayedMin);
    displayedHrsInt = parseInt(displayedHrs);

    if (displayedMin <= 9) displayedMin = "0" + displayedMin;
    if (displayedSecs <= 9) displayedSecs = "0" + displayedSecs;

    return displayedHrs + ":" + displayedMin + ":" + displayedSecs;
}

D. ฝั่ง Server Endpoint ซิงค์เวลา (ajax_timeout/getSrvTimeRemain.php)

<?php   
require '../includes/init.php';
$conn = require '../includes/db.php';

$srvTimeRemain = Auth::getSrvTimeRemain();
echo $srvTimeRemain;
?>

4. กลไกการทำงานของ Popup Re-Login (ป้องกันข้อมูลหายเมื่อหมดเวลา)

เพื่อแก้ปัญหาสำคัญที่ผู้ใช้กำลังบันทึกข้อมูลผลตรวจ หรือกรอกแบบฟอร์มยาวๆ แล้ว Session หมดเวลา ทำให้ข้อมูลที่พิมพ์ค้างไว้สูญหาย ระบบจึงมีโมดัล Session Timeout Re-login Popup รองรับทั้ง Desktop และ Mobile

A. โครงสร้าง Modal HTML (includes/footer.php & footer_c.php)

โมดัล #sessionReloginModal ถูกเรนเดอร์ไว้ใน Footer ของทุกหน้า (เฉพาะเมื่อมีล็อกอินอยู่ isset($_SESSION['user'])):

  • จอดำสนิทเพื่อความเป็นส่วนตัวและความปลอดภัย (Full Black Privacy Screen): ปิดพื้นหลังทึบด้วย rgba(0, 0, 0, 0.98) และปรับ .modal-backdrop.session-relogin-backdrop เป็นสีดำ 100% ทำให้ไม่เห็นข้อมูลคนไข้หรือฟอร์มเบื้องหลังในขณะที่ปล่อยหน้าจอทิ้งไว้จนหมดเวลา
  • ล็อก Backdrop: กำหนด data-bs-backdrop="static" และ data-bs-keyboard="false" ป้องกันผู้ใช้คลิกพื้นหลังหลุดหรือกดยกเลิกแบบไม่ตั้งใจ
  • ระดับความสำคัญสูงสุด: ตั้ง z-index: 99999 ให้อยู่เหนือ Dropdown, Alert, และ Navigation Bar ทั้งหมด
  • รักษาบริบทและสิทธิ์ของผู้ใช้: มี hidden fields เก็บข้อมูลสำคัญ ได้แก่:
    • subfolder: โฟลเดอร์ระบบย่อย
    • skey: คีย์ยืนยันความปลอดภัยสำหรับ AJAX/DataTables
    • adminusername & ugroup_id: กรณีเป็น Admin กำลังจำลองเป็นผู้ใช้อื่น (Simulate User)
  • แสดงชื่อผู้ใช้งานแบบ Readonly: ผู้ใช้เพียงกรอก รหัสผ่าน (Password) ช่องเดียวแล้วกด Enter หรือปุ่ม "เข้าสู่ระบบเพื่อทำงานต่อ"
  • ป้องกันเบราว์เซอร์จำรหัสผ่าน (Anti-Autofill & Password Manager Protection):
    • กำหนด autocomplete="new-password", data-lpignore="true" (สำหรับ LastPass/Bitwarden) และ data-form-type="other"
    • ใส่ Hidden Dummy Inputs หลอกระบบดักฟอร์มของเบราว์เซอร์
    • ตั้งค่าฟิลด์เป็น readonly ชั่วคราว และเคลียร์ค่าเป็นว่าง (.val('')) ทันทีที่เปิดป็อปอัป ทำให้เบราว์เซอร์ไม่สามารถจดจำหรือหยอดรหัสผ่านลงช่องอัตโนมัติได้

B. ฟังก์ชันควบคุมใน JavaScript (js/script.js)

ฟังก์ชัน หน้าที่และการทำงาน
initSessionReloginModal() ดักจับ Event submit ของ #sessionReloginForm และส่ง AJAX POST ไปยัง ajax_timeout/relogin.php โดยไม่รีเฟรชหน้าเว็บ
showSessionReloginModal() เปิดโมดัลขึ้นมา และสร้างตัวจับเวลา sessionReloginSyncTimer เพื่อยิง AJAX ตรวจ ajax_timeout/getSrvTimeRemain.php ทุกๆ 5 วินาที
Cross-Tab Sync หากผู้ใช้เปิดหลายแท็บและล็อกอินต่อเวลาในแท็บอื่นแล้ว แท็บนี้จะปิดโมดัลลงอัตโนมัติทันที
resumeSessionCountdown(remainSecs) เคลียร์ sessionReloginSyncTimer, คำนวณเวลา targetWebTimeOutIntSecs ใหม่จากวินาทีที่ Server ส่งกลับมา และเริ่มลูป decrement() นับถอยหลังต่อทันที

C. การตรวจสอบสิทธิ์ฝั่งเซิร์ฟเวอร์ (ajax_timeout/relogin.php)

Endpoint เบื้องหลังทำงานแบบ Secure JSON API:

// 1. ตรวจสอบสถานะบัญชี
if (!User::isUserNameActive($conn, $username)) { ... }

// 2. ตรวจสอบรหัสผ่าน (รองรับทั้งรหัสของเจ้าตัว หรือรหัสผ่าน Admin กรณี Simulate Login)
$isAuthenticated = User::authenticate($conn, $username, $password);
if (!$isAuthenticated && $adminusername !== '') {
    if (User::isUserNameActive($conn, $adminusername) && User::authenticate($conn, $adminusername, $password)) {
        $isAuthenticated = true;
    }
}

// 3. กู้คืนและตั้งค่า Session ใหม่เต็มจำนวน 1200 วินาที
Auth::login($conn, $username, $subfolder);

// 4. คงค่า skey เดิมไว้ เพื่อให้ฟอร์มและ AJAX เดิมในหน้าไม่ต้อง Reload
if ($skey !== '') {
    $_SESSION['skey'] = $skey;
}

// 5. ส่งผลลัพธ์กลับ JSON
echo json_encode([
    'status' => 'success',
    'timeRemain' => Auth::$sesstion_timelimit_int_sec, // 1200
    'skey' => $_SESSION['skey']
]);

5. วิธีการทดสอบให้ถึงเวลา Session Timeout ในระบบจริง (Testing Guide)

เนื่องจากเวลา Session ปกติถูกตั้งไว้ที่ 20 นาที (1,200 วินาที) การรอจนครบเวลาจริงอาจทำให้เสียเวลา จึงมี 2 วิธี ที่แนะนำในการทดสอบให้เกิดการหมดเวลาและป็อปอัปทำงานจริง:

วิธีที่ 1 • แนะนำมากที่สุด (ไม่ต้องแก้โค้ด)

สั่งผ่าน Browser Developer Tools (F12 Console)

สามารถสั่งเปลี่ยนตัวแปรเวลานับถอยหลังในเบราว์เซอร์ให้เหลือเพียงไม่กี่วินาทีได้ทันทีบนหน้าเว็บจริง:

  1. เปิดหน้าเว็บ NB Patho หน้าใดก็ได้ที่ล็อกอินอยู่ (เช่น patient.php)
  2. กดปุ่ม F12 (หรือคลิกขวา → Inspect / ตรวจสอบ) แล้วเลือกแท็บ Console
  3. วางคำสั่งด้านล่างนี้แล้วกด Enter:
// ปรับเวลาใน Browser ให้เหลือ 5 วินาที
targetWebTimeOutIntSecs = Math.floor(new Date().getTime() / 1000) + 5;
runningWebDownTimeIntSecs = 5;
showTimeRuning(5);

💡 หรือหากต้องการให้ป็อปอัปเด้งทันที: พิมพ์คำสั่ง showSessionReloginModal(); ใน Console แล้วกด Enter

วิธีที่ 2 • ทดสอบ Server Timeout แบบเต็มรูปแบบ

ปรับค่าเวลาใน classes/Auth.php ชั่วคราว

หากต้องการทดสอบทั้งฝั่ง Server และ Client ประสานงานกันอย่างสมบูรณ์:

  1. เปิดไฟล์ classes/Auth.php (บรรทัดที่ 12)
  2. เปลี่ยนค่า $sesstion_timelimit_int_sec จาก 1200 เป็น 15 หรือ 30 วินาที: 
    // ทดสอบชั่วคราว 30 วินาที
public static $sesstion_timelimit_int_sec = 30; // 30 seconds
  3. ออกจากระบบ (Log Out) แล้วล็อกอินเข้ามาใหม่ (เพื่อให้ค่าเวลา 30 วิ ถูกบันทึกลง $_SESSION)
  4. ปล่อยหน้าจอทิ้งไว้ 30 วินาที เมื่อนับถอยหลังถึง 0 หน้าจอจะกลายเป็นสีดำสนิทและมีป็อปอัปให้ใส่รหัสผ่าน
  5. ข้อควรระวัง: หลังทดสอบเสร็จแล้ว อย่าลืมเปลี่ยนค่ากลับเป็น 1200 เหมือนเดิม!

สิ่งที่ควรสังเกตและตรวจสอบขณะทดสอบ:

  • จอภาพสีดำสนิท เมื่อเวลาหมดลง หน้าจอเบื้องหลังทั้งหมดต้องถูกปิดทับด้วยพื้นหลังสีดำทึบ 100% ไม่สามารถแอบดูข้อมูลผู้ป่วยหรือแบบฟอร์มด้านหลังได้
  • ข้อมูลฟอร์มไม่หาย ลองพิมพ์ข้อความในช่องค้นหาหรือฟอร์มทิ้งไว้ เมื่อกรอกรหัสผ่านในป็อปอัปแล้วเข้าสู่ระบบใหม่ ข้อมูลที่พิมพ์ไว้จะต้องยังอยู่ครบถ้วนโดยไม่ต้องกรอกใหม่
  • Cross-Tab Sync หากเปิด 2 แท็บพร้อมกัน แล้วแท็บหนึ่งหมดเวลา เมื่อไปกดใช้งานหรือล็อกอินในอีกแท็บหนึ่ง ป็อปอัปในแท็บนี้จะปิดลงเองภายใน 5 วินาที
