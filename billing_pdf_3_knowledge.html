3. Step-by-Step User & AJAX Workflow

STEP 1

Fetch & Populate by Date Range

Click #btn_get_bill_by_range. Fires DataTable AJAX + 9 synchronous AJAX requests to populate inputs and draw G2, G3, G4 tables.

STEP 2

Review / Edit Form Inputs

User enters invoice_sub_number & invoice_number, and can tweak Thai dates, hospital info, or service-type rows in #bill_hospital_by_service_price.

STEP 3

Preview on Web Page

Click #btn_bill_preview_web. Reads editable service table & inputs and injects values into all .bill_* spans and Page 1–3 tables.

STEP 4

Export PDF (Layout or Official)

Click #btn_export_bill_pdf_layout or #btn_export_bill_pdf. Submits HTML of #bill_page1–#bill_page5 to billing_pdf_show_3.php.

6. mPDF Generator Engine (billing_pdf_show_3.php)

  • Font Configuration: Uses custom CustomLanguageToFontImplementation defaulting to angsana (angsau.ttf with useOTL => 0xFF and useKashida => 75 to prevent Thai vowel overlapping) and sarabun (THSarabunNew.ttf).
  • Layout Mode Flag: Checks isset($_POST['layout']):
    • Official PDF (#btn_export_bill_pdf): $hideLayout = true → strips border: 1px solid green; and color:red from all pages before rendering.
    • Layout Preview (#btn_export_bill_pdf_layout): $hideLayout = false → keeps green table cell borders and red dynamic text highlights visible for layout inspection.
  • Page Orientations & Margins:
    • page1, page2, page3, page5: Portrait A4 (margins: left/right/top/bottom = 25mm).
    • page4 (Group 2 SN table): Landscape A4 via $mpdf->AddPage('L','','','','',15,15,17,17,0,0).
  • Large HTML Chunking: Splits each page's HTML string into 1,000,000-byte chunks before calling $mpdf->WriteHTML() to avoid mPDF PCRE backtrack limits on large hospital bills.

7. Modification Rules, Extending & Validation Checklist

Critical Isolation Rule: Never modify V1 (billing_pdf.php) or V2 (billing_pdf_2.php) files when working on V3. All V3 template and generator changes must stay in *_3.php files. Take care when touching shared AJAX files in ajax_billing/ that do not have a _3 suffix.

How to Add a New PDF Page (e.g., page6 / page7)

  1. Create template pdf_invoice/newtemplate_3.php.
  2. Load it in billing_pdf_3.php via file_get_contents('pdf_invoice/newtemplate_3.php') inside a new <span id="bill_pageX"> container.
  3. In #btn_export_bill_pdf and #btn_export_bill_pdf_layout click handlers, read $('#bill_pageX').html() and append <textarea hidden name="pageX"> to frm.
  4. In billing_pdf_show_3.php, add $mpdf->AddPage(...) and write $_POST['pageX'] before $mpdf->Output().

How to Clone V3 into V4 (billing_pdf_4.php)

  1. Copy billing_pdf_3.php → billing_pdf_4.php and billing_pdf_show_3.php → billing_pdf_show_4.php.
  2. Copy ajax_billing/getBillingGroupBySN_3.php → getBillingGroupBySN_4.php.
  3. Copy all 5 templates in pdf_invoice/*_3.php → pdf_invoice/*_4.php.
  4. Update internal references in billing_pdf_4.php and billing_pdf_show_4.php from _3 to _4.
  5. Add #billing_pdf_tab_4 link in includes/header.php.
